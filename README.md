# Adventure Escape SA - Website Repository

Welcome to the official repository for the **Adventure Escape SA** nature-themed adventure and booking web platform. This project provides a fully responsive, semantic, and interactive web experience designed to showcase eco-adventures, camping excursions, mountain hiking trails, kayaking routes, and team-building packages.

---

## Technologies Used

HTML5: Semantic markup structuring all web pages, including accessible landmark elements (header, nav, main, section, footer).

CSS: Custom styling utilizing CSS Flexbox and Grid layouts, fluid typography, and media queries for seamless mobile, tablet, and desktop responsiveness.

JavaScript: Client-side scripting handling interactive menu toggles, dynamic DOM updates, and form validations.

Figma: Used during the initial design phase for wireframing, layout prototyping, and Auto Layout UI components.

## Design Choices & Rationale

Semantic HTML5 Architecture: Every page utilizes descriptive tags to improve screen reader accessibility, SEO indexing, and code maintainability.

Mobile-First Responsive Design: CSS media queries adapt layouts fluidly across varying viewports, ensuring touch-friendly navigation on mobile devices and expansive multi-column grids on desktops.

Natural Color Palette: Earthy tones, greens, and browns were selected to visually reinforce the nature and outdoor exploration theme of the brand.

Optimized Typography: Clean sans-serif font declarations ensure high readability across both high-resolution desktop monitors and smaller mobile screens.

## Project Structure

The project follows a clean, modular file structure optimized for readability and responsive multi-device design:

```text
Website/
│
├── css/
│   └── style.css          # Core stylesheet containing layout rules and media queries
│
├── images/                # Visual assets, logos, and promotional imagery
│
├── js/
│   └── script.js          # Client-side interactivity, navigation toggles, and dynamic UI logic
│
├── about.html             # Company background, mission, and core values
├── activities.html        # Overview directory of all available outdoor adventures

├── team-building.html     # Corporate and group outdoor team-building packages
